# GA · IBKR Tick Collector

Repository separato dal progetto GA per raccogliere quotazioni EURUSD
tick-by-tick e preparare i dati per un simulatore di trading.

La prima versione girerà su una macchina di sviluppo con IB Gateway in
modalità Paper Trading e accesso API in sola lettura. Questo commit iniziale
contiene la specifica e un esempio di configurazione. Il collector è da
implementare seguendo [SPEC.md](SPEC.md).
